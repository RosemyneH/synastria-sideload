All Synastria CLua functions

Every name WoWExt.dll registers into the game Lua state. Live calls return item-file fields, init-game attune data, the affix snapshot, or a client DBC name. Empty calls are registered and still return nothing. The quest, spell, loot, transmog, and map groups are the rest of the work.
